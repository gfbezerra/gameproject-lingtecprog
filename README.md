# Projeto do jogo: Fuga da Prisão

## 1. Descrição do Sistema

Este projeto é voltado para a disciplina de linguagem e técnicas de programação, na qual, iremos desenvolver um jogo em linguagem C. No jogo fuga da prisão, você tem a missão de coletar as chaves do labirinto enquanto agentes policiais fazem de tudo para te encontrar e capturar. Seja agil e fuja antes que eles te pegem.
